# Submission checklist
- [ ] Confirm student, semester, faculty mentor, and college metadata in the report.
- [ ] Install requirements and run `python -m intelligraph.app`.
- [ ] Generate a learning path in the browser.
- [ ] Mark mastered topics and confirm they are excluded.
- [ ] Check `/api/graph` and `/api/path?target=Machine%20Learning`.
- [ ] Run `python -m unittest discover -s tests -v`.
- [ ] Capture genuine screenshots of the running app and tests.
- [ ] Upload the extracted repository folder to a GitHub repository.
- [ ] Confirm the GitHub URL is the actual created repository URL.
